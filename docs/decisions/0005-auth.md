# 5. Better Auth, self-hosted, email + password

Date: 2026-09-10
Status: accepted

## Context

Spec calls for "simple, modern user auth" with email + password. We want it
self-hosted (no third-party auth service) and working on both web and the Expo
app.

## Decision

Use **Better Auth**:

- Email + password, Argon2id hashing (Better Auth default).
- Web: HTTP-only session cookies.
- Expo: the `@better-auth/expo` plugin, session token in the iOS keychain via
  `expo-secure-store`.
- Drizzle adapter against our own schema (`provider: "pg"`).
- One custom user field, `timezone` (IANA), captured at signup — needed for
  timezone-correct view calculations later.

## Consequences

- Auth tables (`user`, `session`, `account`, `verification`) are created by
  migration `0001_init`; they must track Better Auth's expected shape when it is
  upgraded.
- Email verification and password reset are off for Phase 1; add when email
  delivery is set up.
